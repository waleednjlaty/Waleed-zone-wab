# جودة محتوى الصفحات قبل مراجعة تحقيق الدخل

صفحة تحتوي على صورة وعنوان وزر تحميل فقط ضعيفة للمراجعة. أضف معلومات مفيدة للقارئ قبل التفكير في الإعلانات؛ طول النص وحده لا يثبت الجودة أو الحقوق ولا يضمن موافقة Google.

## الحقول الموصى بها

- اسم التطبيق أو اللعبة بدقة، ووصف أصلي يشرح الاستخدام والفوائد والقيود دون حشو أو وعود مضللة.
- الإصدار، المنصة، التصنيف، المطوّر أو الناشر إن عُرف، وحجم الملف إن عُرف.
- التحديثات أو التغييرات، التوافق ومتطلبات التشغيل، وملاحظة تحريرية مفيدة من المالك.
- مصدر المعلومات والملف وطريقة التوزيع، وأساس الحقوق مع دليل أو مرجع محفوظ في مراجعة المالك الداخلية.

لا تخترع إصدارًا أو مطوّرًا أو ترخيصًا أو متطلبات تشغيل. المعلومات غير المعروفة تظل غير معروفة. لا تنسخ وصفًا محميًا بالكامل ولا توحِ بوجود علاقة رسمية غير مثبتة مع الناشر.

## مراجعة الحقوق والسياسات

كون التطبيق مجانيًا أو مفتوح المصدر لا يثبت تلقائيًا حق إعادة توزيع كل ملف أو أصل أو تعديل. راجع الترخيص والإذن، الملف الفعلي ووجهته في Telegram، والروابط الخارجية وتجربة الصفحة. سجّل أساس الحقوق والملاحظات اللازمة دون بيانات شخصية حساسة أو مفاتيح سرية.

شغّل `npm run monetization:audit` صراحةً على قاعدة مصرح بمراجعتها. التقرير للقراءة فقط: كل علم يعني **مراجعة بشرية فقط**؛ ليس حكمًا قانونيًا، ولا حظرًا تلقائيًا، ولا تحويلًا إلى مؤهل. بعد المراجعة يغيّر المالك وحده الحالة من `/admin#monetization`. اترك الحالات غير المحسومة غير مراجعة أو محظورة للإعلانات.

تغيّر محتوى التطبيق أو مصدر التسليم يسحب أهلية المراجعة السابقة. العداد لا يسحبها. حد الوصف البالغ 200 حرف في موضع الإعلان مجرد حاجز كثافة إضافي؛ لا يغني عن جودة المحتوى أو مراجعة كامل الكتالوج. لا تعرض الإعلانات في صندوق التحميل أو بجوار زر التحميل أو في العد التنازلي.
